# 小学四则运算自动生成器

一个用 Python 编写的命令行小程序，能自动生成符合小学生计算练习要求的四则运算题目，并能对学生作答进行自动批改。

本项目源自《软件工程》个人项目作业，要求实现一个命令行程序，支持自然数、真分数（含带分数）的四则运算，且题目不重复、过程不出现负数。

---

## 功能特性

- 支持 **自然数、真分数、带分数** 的混合四则运算
- 支持 `+` `-` `×` `÷` 四种运算符，**每道题运算符个数 ≤ 3**
- 支持 **括号** 的正确渲染与计算
- 自动保证：
  - 减法子表达式 `e1 − e2` 中 `e1 ≥ e2`（过程不出现负数）
  - 除法除数不为 0，结果用分数精确表示
- **题目去重**：通过对 `+`、`×` 交换左右子树做规范化，杜绝 `23+45` 与 `45+23` 这类等价题目
- 一次性可生成 **10000+** 道不重复题目（实测约 0.3 秒）
- 支持 **判题模式**：自动批改学生答案，输出对错统计
- 仅依赖 Python 标准库，无需安装第三方包

---

## 环境要求

- Python 3.7 及以上（使用 `fractions.Fraction` 做精确分数运算）
- 无任何第三方依赖

## 快速开始

### 1. 生成题目

```bash
python main.py -n 10 -r 10
```

- `-n 10`：生成 10 道题目
- `-r 10`：所有数值（自然数、真分数分子/分母、带分数整数部分）均小于 10

运行后会在 **当前工作目录** 生成两个文件：

- `Exercises.txt`：题目文件
- `Answers.txt`：标准答案文件

示例输出（`Exercises.txt`）：

```
  1. 9'3/5 + 6 + 7'1/2 - 5 =
  2. 1'2/9 ÷ 5 =
  3. 3 - (1 + 1/3 ÷ 3/4) =
  4. 4 × (1/3 + 6) =
```

示例输出（`Answers.txt`）：

```
  1. 18'1/10
  2. 11/45
  3. 1'5/9
  4. 25'1/3
```

### 2. 批改答案

把学生作答保存为 `StudentAnswers.txt`，然后运行：

```bash
python main.py -e Exercises.txt -a StudentAnswers.txt
```

会在当前目录生成 `Grade.txt`：

```
Correct: 8 (1, 3, 4, 5, 6, 8, 9, 10)
Wrong: 2 (2, 7)
```

### 3. 查看帮助

```bash
python main.py -h
```

## 题目格式约定

| 表示 | 含义 |
|---|---|
| `3` | 自然数 3 |
| `3/5` | 真分数 五分之三 |
| `2'3/8` | 带分数 二又八分之三 |
| `+` `-` `×` `÷` | 四则运算符 |
| `(` `)` | 括号 |

运算符和等号前后均有一个空格分隔，例如 `1 + 2 × 3 =`。

## 实现要点

### 表达式树与精确计算

程序内部把每道题目表示成一棵表达式树（`Num` 叶子节点 + `Bin` 二叉运算节点），所有数值使用标准库 `fractions.Fraction` 表示，从根本上杜绝浮点误差，例如：

```
1/6 + 1/8 = 7/24
```

### 括号渲染策略

在把表达式树渲染成字符串时，根据运算符优先级和结合性决定是否需要加括号：

- 子表达式优先级低于父节点时，必须加括号
- 右子树与父节点同优先级时，若父运算符是 `-` 或 `÷`，必须加括号（因为它们不满足交换律）

例如：`4 × (1/3 + 6)` 中括号不能省略，否则会变成 `4 × 1/3 + 6`。

### 去重算法

对 `+` 和 `×` 这两种满足交换律的运算符，在生成"规范化 key"时把左右子树递归规范化后排序；对 `-` 和 `÷` 则保持顺序。这样 `23+45` 和 `45+23` 会产生相同的 key，从而被识别为重复题目。

### 生成约束

- 减法：左子树生成后，右子树在重试机制下确保不大于左子树
- 除法：右子树重试到非零为止
- 运算符数量：在 1~3 之间随机
